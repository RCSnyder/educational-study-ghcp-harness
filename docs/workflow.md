# Recommended Workflows

## Domain exploration

```text
/es-domain [field]
/es-substrate [field]
/es-primitives [field]
/es-core [topic] for [goal]
/es-ground [topic]
/es-practice [topic] at [level]
/es-goodenough [topic] for [goal]
/es-next
```

## Textbook problem grinding

```text
/es-textbook [book/chapter]
/es-problemcore [chapter/problem set]
/es-problem [paste problem]
# Try yourself first.
/es-solve [paste problem + my attempt]
/es-drill [topic] for [goal]
/es-goodenough [topic] for [next topic]
/es-next
```
