# nWave-Inspired Product Notes

This pack borrows useful product patterns from nWave-style agent workflows but applies them to academic learning and research navigation.

## Adopted patterns

- Short command namespace: `/es-*`.
- Concierge command: `/es-buddy`.
- Human gates before moving to the next phase.
- Artifact-based handoffs instead of chat-only memory.
- Rigor profiles to match effort to stakes.
- Command catalog so the buddy can route users.

## Improvements for academic learning

1. Evidence tiers, not just workflow steps.
2. Claim ledgers for hallucination control.
3. Textbook/review/primary-source grounding.
4. Practice labs that test transfer, not recognition.
5. Critical reasoning primitives for every domain.
6. Anti-rabbit-hole controls to prevent infinite prerequisites.
7. Good-enough gates tied to tasks, not vibes.

## Product position

Educational Study GHCP Harness is not a coding delivery workflow. It is a source-grounded academic navigation workflow:

```text
continent -> mountain ranges -> trailheads -> core -> drills -> audit -> next move
```

## Core promise

Do not merely feel oriented. Demonstrate orientation by naming objects, methods, evidence, assumptions, representative problems, and what would change your mind.
