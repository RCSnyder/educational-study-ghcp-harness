## Recommended product commands

- Start here: `/es-buddy What should I do next?`
- Start a new objective: `/es-new [goal]`
- Resume: `/es-continue [artifact or goal]`
- Set rigor: `/es-rigor thorough`
- Review before moving on: `/es-review [artifact]`

## Naming rule

All original commands remain available. The productized commands are the same commands with the `es-` prefix, following the same style as products that use a short namespace prefix such as `/nw-*`.
